# Code of Conduct

We want participation in UniFormat to be respectful and constructive for everyone.

**Expected behaviour:** be kind and patient, assume good faith, give and accept feedback gracefully, focus on what is
best for the project and the people using it.

**Unacceptable behaviour:** harassment, discrimination, personal attacks, trolling, publishing others' private
information, or any conduct that would be inappropriate in a professional setting.

Maintainers may remove or edit comments, commits, issues and other contributions that do not follow this code, and may
temporarily or permanently ban contributors for behaviour they judge harmful.

To report a problem, contact the maintainers privately through the organisation's GitHub security/contact channel.

This code of conduct is inspired by the [Contributor Covenant](https://www.contributor-covenant.org) (version 2.1,
CC BY 4.0), whose full text can replace this one at any time.
